# Chignolin models

Exported slow-mode models used in the chignolin benchmarks.

| Path | Description |
| --- | --- |
| `SelfTICA/model.pt` | SelfTICA model used by the main chignolin workflow |
| `SelfTICA/model_shaw.pt` | Additional archived SelfTICA model used by the `SelfTICA_shaw` workflow |
| `DeepTICA/model.pt` | DeepTICA reference model |
| `DeepTICA/model_shaw.pt` | Additional archived DeepTICA model |

Use the exact model referenced by the associated PLUMED or analysis input.

See the parent [chignolin README](../README.md) and the [reproduction guide](../../docs/REPRODUCIBILITY.md).
