# Tri-well models

Exported models used in the two-dimensional tri-well benchmarks.

| Path | Description |
| --- | --- |
| `unbiased/model_1.0kbt.pt` | Model trained for the unbiased 1.0 kBT benchmark |
| `biased/` | Models from biased-data experiments, including x/y and linear/nonlinear predictor variants |
| `replicates/SelfTICA/` | SelfTICA model collection used for repeated/reference comparisons |
| `replicates/DeepTICA/` | DeepTICA reference model collection |

The archived variants correspond to different experiments in the paper. Use the exact model referenced by the associated simulation or analysis input.

See the parent [tri-well README](../README.md) and the [reproduction guide](../../docs/REPRODUCIBILITY.md).
